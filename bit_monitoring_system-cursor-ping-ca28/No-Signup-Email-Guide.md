# 🚀 회원가입 없는 이메일 발송 가이드

네트워크 모니터링 시스템에서 **어떤 서비스에도 가입하지 않고** 바로 이메일을 보낼 수 있는 방법들을 안내합니다.

## 📧 지원하는 방법들

### 1️⃣ Formspree (가장 추천) ⭐

**장점:**
- ✅ 회원가입 완전 불필요
- ✅ 이메일 주소만 입력하면 바로 사용
- ✅ 월 50개 이메일 무료
- ✅ 실제 이메일 발송
- ✅ 설정 1분 완료

**사용법:**
1. 받을 이메일 주소 입력 (예: `admin@company.com`)
2. "설정 저장" 클릭
3. 끝! 바로 사용 가능

**작동 원리:**
- Formspree가 이메일 주소를 기반으로 임시 엔드포인트 생성
- 첫 번째 이메일 발송 시 Formspree에서 확인 이메일 발송
- 확인 후 정상 작동

### 2️⃣ 기본 이메일 클라이언트 (100% 호환)

**장점:**
- ✅ 항상 사용 가능
- ✅ 설정 불필요
- ✅ Outlook, Thunderbird, Apple Mail 등 지원
- ✅ 완전 무료

**사용법:**
1. 받을 이메일 주소 입력
2. 알림 발생 시 기본 이메일 프로그램이 자동으로 열림
3. 내용 확인 후 "보내기" 클릭

**작동 원리:**
- `mailto:` 링크를 생성하여 기본 이메일 클라이언트 실행
- 제목과 내용이 미리 작성된 상태로 열림

### 3️⃣ 웹훅 (고급 사용자용)

**장점:**
- ✅ 다양한 서비스 연동 가능
- ✅ Slack, Discord, Teams 알림
- ✅ 자동화 가능
- ✅ 커스터마이징 자유도 높음

**지원 서비스:**
- **Zapier**: 무료 플랜 월 100개 작업
- **IFTTT**: 무료 플랜 월 2개 애플릿
- **Make.com**: 무료 플랜 월 1,000개 작업
- **Discord Webhook**: 완전 무료
- **Slack Webhook**: 완전 무료

## 🚀 빠른 시작 가이드

### 방법 1: Formspree 사용 (추천)

```
1. 네트워크 모니터링 시스템 → 설정 클릭
2. "회원가입 없는 이메일 발송" 섹션 찾기
3. "Formspree" 체크박스 활성화
4. 받을 이메일 주소 입력 (예: admin@company.com)
5. "설정 저장" 클릭
6. "테스트 발송" 버튼으로 동작 확인
```

### 방법 2: 기본 이메일 클라이언트 사용

```
1. "기본 이메일 클라이언트" 섹션에 이메일 주소 입력
2. "설정 저장" 클릭
3. 알림 발생 시 Outlook 등이 자동으로 열림
```

## 🔧 상세 설정 방법

### Formspree 설정

1. **이메일 주소 입력**
   ```
   받을 이메일: admin@company.com
   ```

2. **첫 번째 이메일 발송**
   - 테스트 발송 시 Formspree에서 확인 이메일 발송
   - 이메일의 "Confirm" 링크 클릭
   - 이후 모든 이메일이 정상 발송됨

3. **제한사항**
   - 무료: 월 50개 이메일
   - 유료: 월 1,000개 이메일 ($10/월)

### 웹훅 설정 예시

#### Discord 웹훅
```
1. Discord 서버 → 채널 설정 → 연동 → 웹훅
2. 웹훅 생성 후 URL 복사
3. 시스템에 웹훅 URL 입력
```

#### Slack 웹훅
```
1. Slack 앱 → Incoming Webhooks 활성화
2. 채널 선택 후 웹훅 URL 생성
3. 시스템에 웹훅 URL 입력
```

#### Zapier 웹훅
```
1. Zapier → Zaps → Create Zap
2. Trigger: Webhooks by Zapier → Catch Hook
3. Action: Email by Zapier → Send Outbound Email
4. 웹훅 URL을 시스템에 입력
```

## ❓ 자주 묻는 질문

### Q: Formspree 확인 이메일이 안 와요
**A:** 스팸 폴더 확인, 다른 이메일 주소로 재시도

### Q: 기본 이메일 클라이언트가 안 열려요
**A:** 
- Windows: 기본 앱 설정에서 메일 앱 설정
- Mac: Mail.app 또는 Outlook 설치
- Linux: Thunderbird 설치

### Q: 웹훅이 작동하지 않아요
**A:** 
- URL 정확성 확인
- 서비스 상태 확인
- 브라우저 콘솔에서 에러 메시지 확인

### Q: 이메일이 발송되지 않아요
**A:**
1. 브라우저 콘솔 확인
2. 시스템 로그 확인
3. 각 방법별로 개별 테스트
4. 네트워크 연결 상태 확인
