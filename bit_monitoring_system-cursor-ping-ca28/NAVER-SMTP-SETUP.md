# 📧 네이버 메일 SMTP 설정 가이드

네트워크 모니터링 시스템에서 네이버 메일 SMTP를 사용한 이메일 알림 설정 방법입니다.

## 🚀 빠른 시작

### 1단계: 네이버 메일 설정

1. **네이버 메일 접속**
   - [mail.naver.com](https://mail.naver.com) 접속
   - 네이버 계정으로 로그인

2. **환경설정으로 이동**
   - 우측 상단 "설정" 클릭
   - "환경설정" 선택

3. **POP3/IMAP 설정 활성화**
   - "POP3/IMAP 설정" 탭 선택
   - "IMAP/SMTP 사용" 체크박스 활성화
   - "저장" 버튼 클릭

4. **2단계 인증 확인**
   - "보안" 탭에서 2단계 인증 상태 확인
   - 2단계 인증이 활성화된 경우 "앱 비밀번호" 생성 필요

### 2단계: 앱 비밀번호 생성 (2단계 인증 사용 시)

1. **네이버 계정 설정**
   - [nid.naver.com](https://nid.naver.com) 접속
   - "보안" → "2단계 인증" 선택

2. **앱 비밀번호 생성**
   - "앱 비밀번호" 클릭
   - "새 앱 비밀번호" 생성
   - 앱 이름: "네트워크 모니터링"
   - 생성된 **16자리 비밀번호** 복사

### 3단계: 서버 실행

```bash
# 의존성 설치
npm install

# 서버 실행 (포트 3001)
PORT=3001 npm start
```

### 4단계: 네이버 메일 SMTP 설정

1. **웹 브라우저**에서 `http://localhost:3001` 접속
2. **설정** 버튼 클릭
3. **"네이버 메일"** 탭 선택
4. 네이버 메일 정보 입력:
   - **네이버 메일 주소**: your-email@naver.com
   - **비밀번호**: 일반 비밀번호 또는 앱 비밀번호
   - **발신자 이메일**: your-email@naver.com
   - **수신자 이메일**: admin@company.com, manager@company.com

5. **"테스트 발송"** 버튼으로 동작 확인
6. **"설정 저장"** 버튼으로 저장

## 🔧 상세 설정

```
SMTP 서버: smtp.naver.com
SMTP 포트: 587
보안: TLS
인증: 네이버 계정 + 비밀번호 (또는 앱 비밀번호)
```

## 📋 사용법

### 호스트 추가

1. **"호스트 추가"** 버튼 클릭
2. 호스트 정보 입력:
   - **이름**: 서버 이름 (예: "웹서버")
   - **IP 주소**: 모니터링할 IP (예: "8.8.8.8")
   - **설명**: 선택사항

3. **"추가"** 버튼 클릭

### 모니터링 시작

- 호스트 추가 후 **자동으로 모니터링 시작**
- **30초마다** ping 테스트 실행
- **오프라인 감지 시** 자동으로 이메일 알림 발송

### 알림 확인

- **이메일**: 설정한 수신자에게 자동 발송
- **브라우저 알림**: 실시간 팝업 알림
- **로그**: 시스템 내 알림 기록

## 🧪 테스트 방법

### 1. 이메일 설정 테스트

```bash
# 네이버 메일 SMTP 연결 테스트
node test-email.js
```

### 2. 호스트 모니터링 테스트

1. **존재하지 않는 IP** 추가 (예: "192.168.999.999")
2. **30초 후** 오프라인 알림 확인
3. **이메일 수신** 확인

### 3. 복구 테스트

1. **올바른 IP**로 변경 (예: "8.8.8.8")
2. **복구 알림** 확인

## 🔍 문제 해결

### 이메일이 발송되지 않는 경우

#### 1. 네이버 인증 오류
```
Error: Invalid login: 535-5.7.8 Username and Password not accepted
```

**해결방법:**
- 2단계 인증이 활성화된 경우 앱 비밀번호 사용
- 일반 비밀번호를 사용하는 경우 2단계 인증 비활성화
- 네이버 계정이 정상적으로 작동하는지 확인

#### 2. IMAP/SMTP 설정 오류
```
Error: Authentication failed
```

**해결방법:**
- 네이버 메일에서 "IMAP/SMTP 사용" 설정 활성화
- 설정 저장 후 몇 분 대기
- 네이버 메일 서비스 상태 확인

#### 3. 연결 오류
```
Error: connect ECONNREFUSED
```

**해결방법:**
- 인터넷 연결 상태 확인
- 방화벽에서 587 포트 차단 여부 확인
- 네이버 메일 서비스 상태 확인

#### 4. 포트 사용 중 오류
```
Error: listen EADDRINUSE
```

**해결방법:**
```bash
# 다른 포트로 실행
PORT=3002 npm start
```

### 모니터링이 작동하지 않는 경우

#### 1. 서버가 실행되지 않음
```bash
# 서버 상태 확인
ps aux | grep node

# 서버 재시작
PORT=3001 npm start
```

#### 2. 데이터베이스 오류
```bash
# 데이터베이스 파일 확인
ls -la network_monitor.db

# 데이터베이스 재생성 (데이터 손실 주의)
rm network_monitor.db
PORT=3001 npm start
```
