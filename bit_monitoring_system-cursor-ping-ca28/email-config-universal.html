🔧 Gmail 설정 방법

  1. Google 계정 설정으로 이동 (myaccount.google.com)
  2. "보안" 탭 선택
  3. "2단계 인증" 활성화 (필수)
  4. "앱 비밀번호" 클릭
  5. "메일" 앱 선택
  6. 생성된 16자리 비밀번호를 아래에 입력

주의: 일반 Gmail 비밀번호가 아닌 앱 비밀번호를 사용해야 합니다!

🔧 네이버 메일 설정 방법

  1. 네이버 메일 설정으로 이동 (mail.naver.com)
  2. "환경설정" → "POP3/IMAP 설정" 선택
  3. "IMAP/SMTP 사용" 활성화
  4. 2단계 인증이 활성화된 경우 "앱 비밀번호" 생성
  5. 일반 비밀번호 또는 앱 비밀번호를 아래에 입력

주의: 2단계 인증이 활성화된 경우 앱 비밀번호를 사용해야 합니다!

🔧 Outlook 설정 방법

  1. Outlook 계정으로 로그인
  2. 계정 설정에서 "보안" 선택
  3. 일반 비밀번호 또는 앱 비밀번호 사용

주의: 일반 Outlook/Hotmail 계정 정보를 사용하세요.

🔧 Yahoo 설정 방법

  1. Yahoo 메일 설정으로 이동
  2. "보안" → "앱 비밀번호" 선택
  3. 새 앱 비밀번호 생성
  4. 생성된 비밀번호를 아래에 입력

주의: Yahoo는 앱 비밀번호를 사용해야 합니다!

🔧 사용자 정의 SMTP 설정

  1. 이메일 제공업체에 문의하여 SMTP 설정 확인
  2. 일반적인 포트: 25, 587 (TLS), 465 (SSL)
  3. 인증 방식과 보안 설정 확인

주의: 제공업체별로 설정이 다를 수 있습니다.

이메일 제공업체의 SMTP 서버 주소
SMTP 포트 번호 (일반적으로 587)
알림을 발송할 이메일 주소
이메일 계정 비밀번호 (2단계 인증 시 앱 비밀번호 사용)
알림 이메일의 발신자 주소
알림을 받을 이메일 주소들 (쉼표로 구분)
