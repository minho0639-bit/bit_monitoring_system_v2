# Ping 모니터링 시스템

리눅스 웹서버에서 ICMP ping을 기반으로 한 장치 모니터링 및 알림 시스템입니다.

## 주요 기능

- **장치 관리**: IP 주소를 가진 장치의 등록, 수정, 삭제
- **실시간 모니터링**: 30초마다 자동 ping 테스트
- **상태 추적**: ping 성공/실패 로그 및 통계
- **이메일 알림**: ping 실패 시 자동 이메일 전송
- **웹 대시보드**: 실시간 모니터링 상태 확인
- **로그 시스템**: 상세한 모니터링 로그 및 알림 기록

## 시스템 요구사항

- Python 3.7+
- Linux 운영체제 (ping 명령어 사용)
- 관리자 권한 (ICMP ping 실행)

## 설치 및 실행

### 1. 의존성 설치

```bash
pip install -r requirements.txt
```

### 2. 환경변수 설정 (선택사항)

```bash
cp .env.example .env
# .env 파일은 Flask 기본 설정만 포함합니다
# 이메일 설정은 웹 인터페이스에서 관리됩니다
```

### 3. 데이터베이스 초기화

```bash
python app.py
# 첫 실행 시 SQLite 데이터베이스가 자동으로 생성됩니다
```

### 4. 웹 서버 실행

```bash
python app.py
```

웹 브라우저에서 `http://localhost:5000`으로 접속하세요.

## 사용법

### 장치 추가

1. "장치 관리" 메뉴에서 "장치 추가" 클릭
2. 장치명, IP 주소, 설명 입력
3. "모니터링 활성화" 체크 후 저장

### 모니터링 확인

1. 메인 대시보드에서 전체 장치 상태 확인
2. 각 장치의 상세 정보 및 통계 조회
3. 최근 알림 및 로그 확인

### 이메일 알림 설정

웹 인터페이스에서 이메일 설정을 구성하세요:

1. 웹 브라우저에서 `http://localhost:8000/email_settings` 접속
2. SMTP 서버 정보 입력:
   - **Gmail**: smtp.gmail.com:587 (앱 비밀번호 사용)
   - **Naver**: smtp.naver.com:587
3. "테스트 이메일 전송" 버튼으로 설정 확인
4. "설정 저장" 버튼으로 저장

## 모니터링 주기

- **Ping 테스트**: 30초마다 실행
- **알림 간격**: ping 실패 시 5분 후 재알림
- **복구 알림**: ping 복구 시 즉시 알림

## 데이터베이스

SQLite 데이터베이스 (`monitoring.db`)에 다음 테이블이 생성됩니다:

- `device`: 모니터링 대상 장치 정보
- `ping_log`: ping 테스트 결과 로그
- `alert_log`: 알림 전송 기록

## 보안 고려사항

- ICMP ping 실행을 위해 관리자 권한이 필요할 수 있습니다
- 이메일 비밀번호는 앱 비밀번호를 사용하세요
- 프로덕션 환경에서는 HTTPS를 사용하세요

## 문제 해결

### Ping 권한 오류

```bash
# Linux에서 ping 권한 설정
sudo setcap cap_net_raw+ep /usr/bin/ping
```

### 이메일 전송 실패

- Gmail의 경우 앱 비밀번호를 사용하세요
- SMTP 서버 설정을 확인하세요
- 방화벽 설정을 확인하세요
