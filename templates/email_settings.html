SMTP 서버 설정
예: smtp.gmail.com, smtp.naver.com
일반적으로 587 (TLS)
Gmail의 경우 앱 비밀번호를 사용하세요.
Gmail: 앱 비밀번호 (16자리) 사용
Naver/Outlook: 일반 비밀번호 사용

ping 실패/복구 알림을 받을 이메일 주소
도움말
Gmail 설정
  • SMTP 서버: smtp.gmail.com
  • 포트: 587
  • 사용자명: Gmail 주소 (예: yourname@gmail.com)
  • 비밀번호: 앱 비밀번호 (16자리) - 앱 비밀번호 생성 방법
Naver 설정
  • SMTP 서버: smtp.naver.com
  • 포트: 587
  • 사용자명: Naver 이메일 주소
  • 비밀번호: Naver 비밀번호
Outlook/Hotmail 설정
  • SMTP 서버: smtp-mail.outlook.com
  • 포트: 587
  • 사용자명: Outlook 이메일 주소
  • 비밀번호: Outlook 비밀번호
Yahoo 설정
  • SMTP 서버: smtp.mail.yahoo.com
  • 포트: 587
  • 사용자명: Yahoo 이메일 주소
  • 비밀번호: 앱 비밀번호 (Yahoo 계정 설정에서 생성)
기타 SMTP 서버
  • 회사 메일: IT 부서에 문의하여 SMTP 서버 정보 확인
  • 기타 제공업체: 해당 이메일 제공업체의 SMTP 설정 확인
알림 조건

ping이 실패하면 5분 후에 이메일 알림을 전송하고, ping이 복구되면 즉시 복구 알림을 전송합니다.
